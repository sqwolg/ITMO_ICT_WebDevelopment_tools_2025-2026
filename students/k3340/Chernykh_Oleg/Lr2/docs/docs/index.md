# Лабораторная работа 2

**Выполнил:** Олег Черных, группа K3340, 2026 год.

## Тема

Сравнение подходов к параллельному выполнению задач на Python: `threading`, `multiprocessing` и `asyncio`.

Лабораторная работа состоит из двух частей:

- вычисление суммы большого диапазона чисел с использованием разных моделей параллелизма;
- параллельный парсинг данных из внешнего API и сохранение результата в базу данных.

## Цель

Цель работы - сравнить, как разные подходы ведут себя на CPU-bound и I/O-bound задачах, и показать, в каких случаях эффективнее использовать потоки, процессы или асинхронное выполнение.

## Реализованные задания

| Раздел | Что реализовано | Основной вывод |
| --- | --- | --- |
| Задание 1 | Подсчет суммы диапазона через потоки, процессы и asyncio | Для CPU-bound задачи лучший результат дает `multiprocessing`, потому что он использует несколько процессов и обходит ограничение GIL |
| Задание 2 | Загрузка todo из `dummyjson.com`, парсинг JSON и сохранение в PostgreSQL | Для сетевых операций быстрее всего работает `asyncio` с `aiohttp`, так как запросы выполняются неблокирующе |

## Общий вывод

Для вычислительной нагрузки процессы эффективнее потоков и корутин, потому что выполняются в разных интерпретаторах Python и могут использовать несколько ядер CPU. Для сетевой нагрузки асинхронный подход оказывается быстрее, потому что основная задержка связана с ожиданием ответа от внешнего сервиса, а не с вычислениями.

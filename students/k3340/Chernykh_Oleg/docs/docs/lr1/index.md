# FastAPI Todo App

**Выполнил:** Олег Черных, группа K3340, 2026 год.

## Тема

Backend-приложение для управления пользователями и todo-задачами на FastAPI.

Проект реализует:

- регистрацию пользователей;
- получение JWT access token;
- авторизацию через Bearer token;
- просмотр, создание, обновление и удаление todo;
- привязку задач к текущему пользователю;
- хранение данных через Tortoise ORM.

## Цель

Цель лабораторной - освоить базовую структуру FastAPI-приложения: маршруты, схемы Pydantic, сервисный слой, ORM-модели, настройки окружения и JWT-аутентификацию.

## Структура проекта

```text
todo_app/
  api/          HTTP endpoints
  schemas/      Pydantic-схемы
  services/     бизнес-логика
  app.py        создание FastAPI-приложения
  models.py     Tortoise ORM модели
  run.py        запуск через uvicorn
  settings.py   настройки из .env
```

## Основной поток работы

1. Пользователь создается через `POST /users/`.
2. Клиент получает JWT через `POST /users/token`.
3. JWT передается в заголовке `Authorization: Bearer <token>`.
4. Пользователь работает только со своими todo через маршруты `/todos`.

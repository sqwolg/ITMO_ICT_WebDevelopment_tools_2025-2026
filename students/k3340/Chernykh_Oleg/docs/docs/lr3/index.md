# Лабораторная работа 3

**Выполнил:** Олег Черных, группа K3340, 2026 год.

## Тема

Контейнеризация backend-системы на FastAPI и интеграция основного приложения с отдельным сервисом парсера.

В лабораторной работе существующие компоненты объединяются в систему из нескольких контейнеров:

- `todo_app` - основное FastAPI-приложение с пользователями, задачами, авторизацией и API;
- `web_parser` - отдельный FastAPI-сервис, который принимает URL и извлекает заголовок HTML-страницы;
- `postgres` - база данных PostgreSQL;
- `redis` - брокер сообщений и backend результатов для Celery;
- `celery_worker` - фоновый worker для асинхронного парсинга.

## Цель

Научиться запускать backend-приложение как набор связанных сервисов через Docker Compose, а также реализовать два варианта взаимодействия с парсером:

1. Синхронный HTTP-вызов parser-service из основного FastAPI-приложения.
2. Асинхронную обработку через очередь Celery и Redis.

## Практический результат

После запуска `docker compose up` система поднимает API, базу данных, парсер, Redis и Celery worker. Пользователь может отправить URL на парсинг, получить результат сразу или поставить долгую операцию в очередь и позднее забрать результат по `task_id`.

## Связанные файлы

- `docker-compose.yaml` - описание всех сервисов.
- `todo-app/Dockerfile` - образ основного FastAPI-приложения.
- `todo-app/Dockerfile.celery_worker` - образ Celery worker.
- `todo-app/todo_app/main.py` - создание FastAPI-приложения.
- `todo-app/todo_app/tasks.py` - Celery-приложение и фоновая задача.
- `web-parser/Dockerfile` - образ сервиса парсера.
- `web-parser/web_parser/main.py` - HTTP API парсера.
